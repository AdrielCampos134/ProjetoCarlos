# Trilha SAEGO de Matematica

Jogo de tabuleiro interativo em HTML, CSS e JavaScript vanilla para revisao de descritores de Matematica do 9o ano.

## Como usar

Abra o arquivo `index.html` no navegador ou publique a pasta em uma hospedagem estatica, como Vercel.

## Recursos

- Multiplayer local para 2 a 4 equipes.
- Tabuleiro serpenteante com 30 casas.
- Dado 3D animado.
- Perguntas por categoria: Algebra e Numeros, Estatistica e Graficos, Geometria, Desafio Roxo e Prisao Matematica.
- Cronometro de 2 minutos e 30 segundos.
- Regras automatizadas de acerto, erro, retorno, prisao e vitoria.
- Ranking final e confetes.
